# Madomi BL Repo

Repositório personalizado para o Madomi contendo apenas as extensões selecionadas para leitura de BL/manhwa em inglês.

Fontes incluídas:
- YaoiScan
- Yaoihub
- Mangago
- Orchisasia
- MangaK
- MangaDex
- MangaPark.tv (unoriginal)
- ManhwaZone

Os APKs/JARs continuam sendo baixados dos releases oficiais do Keiyoushi; este repositório apenas mantém um índice filtrado.
